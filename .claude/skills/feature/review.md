# review

1. Read `context/current-feature.md`. Stop and say so if no feature is loaded (empty Goals).
2. Run the `code-reviewer` agent on the current branch's changes against `main`, including uncommitted changes. Tell it the feature's Goals and Notes so it can check the work against them.
3. Show the agent's findings grouped by severity. Don't edit files or fix anything.
4. Ask which findings, if any, to fix.
